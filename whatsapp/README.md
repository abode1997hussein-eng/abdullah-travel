# بوت الواتساب — سافر مع عبدالله

بوت على **واتساب الرسمي من ميتا** (WhatsApp Business Cloud API)، يشتغل على كلاود فلير بلا سيرفر:

1. **يرسل العروض** (قالب إعلاني معتمد من ميتا) لكل الأرقام المحفوظة، على دفعات يومية حسب حد ميتا، وبساعات الدوام بس (10 الصبح لـ9 بالليل بتوقيت بغداد).
2. **يرد وحده** على اللي يراسل: أرخص التذاكر، الكروبات، الفيزا وأوراقها، وأي مدينة أو دولة ينكتب اسمها. الأسعار من `bot.json` اللي ينبني ويا الموقع من الأكسل، فهي نفس أسعار الموقع.
3. **يحوّل للموظف**: اللي يكتب «موظف» أو «احجز» أو يدز صورة (جواز، مستمسكات) يطلع بصفحة الإدارة، والبوت يسكت وياه 12 ساعة. الموظف يرد من صفحة الإدارة.
4. **«إيقاف»**: اللي يكتبها (أو يدوس زر «إيقاف العروض») ما توصله عروض بعد. الرقم اللي ما عليه واتساب ينشال وحده.
5. **يحمي الرقم**: إذا ميتا نزّلت جودة الرقم أو وكّفت القالب، الإرسال يوكف وحده وتطلع السبب بصفحة الإدارة. وما يرسل لنفس الشخص إعلانين بأقل من 3 أيام.

> ليش مو من رقم الواتساب العادي ببرنامج إرسال جماعي؟ لأن واتساب يحظر الرقم بسرعة إذا أرسل لآلاف الناس من التطبيق العادي، وهذا ضد شروطه. الطريق الرسمي ما ينحظر ما دام الناس ما يبلّغون على الرسائل.

## الكلفة

| الشي | الكلفة |
|---|---|
| كلاود فلير | مجاني (أو 5$ بالشهر إذا كبر الشغل) |
| رسالة العروض (قالب Marketing) للعراق | تقريباً 3 إلى 4 سنت للرسالة. الإرسالة الكاملة للـ30 ألف رقم حوالي ألف دولار |
| ردود البوت على اللي يراسلك (خلال 24 ساعة من رسالته) | أول 1000 رسالة بالشهر مجانية، وبعدها بسعر رسائل الخدمة |

هذا تقدير. السعر الدقيق للعراق بجدول ميتا: <https://developers.facebook.com/docs/whatsapp/pricing>. الدفع يكون ببطاقة بـWhatsApp Manager ← Billing.

**نصيحة توفير:** مو لازم ترسل للـ30 ألف كل مرة. أرسل عرض قوي مرة كل أسبوعين، والبوت يرد على اللي يتفاعل ببلاش.

## كم يوم ياخذ حتى يوصل للكل؟

ميتا تحدد كم شخص تكدر تراسل باليوم:

| الحالة | باليوم |
|---|---|
| حساب جديد بلا توثيق | 250 |
| بعد توثيق الشركة (Business Verification) | 2,000 |
| يرتفع وحده إذا استعملت نص الحد لمدة أسبوع والجودة زينة | 10,000 ثم 100,000 ثم بلا حد |

يعني بعد التوثيق: أول أسبوع 2000 باليوم، وبعدها 10 آلاف باليوم، فالـ30 ألف يخلصون تقريباً بأسبوعين. **اكتب الحد الحالي بصفحة الإدارة** كل ما يرتفع.

## الخطوة 1: حساب ميتا (تسويها مرة وحدة)

1. **حساب الشركة:** ادخل <https://business.facebook.com> وسوّي Business portfolio باسم الشركة.
2. **توثيق الشركة:** Settings ← Security Center ← Start verification. تحتاج وثيقة باسم الشركة (إجازة الشركة أو هوية غرفة التجارة) وفاتورة أو كشف بنفس الاسم والعنوان. هذا يرفع الحد من 250 لـ2000 باليوم.
3. **التطبيق:** ادخل <https://developers.facebook.com/apps> ← Create app ← نوع **Business** ← أضف **WhatsApp**.
4. **الرقم:** WhatsApp ← API Setup ← Add phone number.
   - استعمل **رقم جديد** (شريحة جديدة) ما عليه واتساب، لأن الرقم اللي يصير على الـAPI ما يشتغل بتطبيق الواتساب العادي.
   - اسم العرض: «سافر مع عبدالله» (ميتا توافق عليه).
   - رقم المكتب الحالي يبقى للحجي المباشر، والبوت يعطيه للزبون إذا طلب موظف.
5. **طريقة الدفع:** WhatsApp Manager ← Billing ← أضف بطاقة.
6. **التوكن الدائم:** Business settings ← Users ← **System users** ← Add (Admin) ← Assign assets: التطبيق وحساب الواتساب (Full control) ← **Generate token** ويا الصلاحيات `whatsapp_business_messaging` و`whatsapp_business_management`، والمدة Never. احفظه، هذا `WA_TOKEN`.
7. **رقم تعريف الهاتف:** من WhatsApp ← API Setup انسخ **Phone number ID**، هذا `WA_PHONE_ID`.
8. **App secret:** App settings ← Basic ← App secret ← Show، هذا `WA_APP_SECRET`.

## الخطوة 2: قالب العروض

WhatsApp Manager ← **Message templates** ← Create ← نوع **Marketing** ← Default. مثال:

- **الاسم:** `travel_offers` (حروف إنكليزية صغيرة و`_`)
- **اللغة:** Arabic
- **الهيدر:** Image (صورة العرض، تكدر تاخذها من `promo.html`)
- **النص:**
  ```
  هلا {{1}} 🌹
  عروض سافر مع عبدالله لهالأسبوع:
  {{2}}
  اكتب اسم أي مدينة أو دولة ونرد عليك بالسعر فوراً.
  ```
  (بالأمثلة اكتب: `علي` و`✈️ إسطنبول من 101$`)
- **الأزرار:** Quick reply ← «شوف العروض»، وMarketing opt-out ← «إيقاف العروض».

ميتا توافق عادة خلال دقايق لساعات. بصفحة الإدارة: المتغير الأول `{name}` (ينكتب اسم الزبون وحده) والثاني نص العرض.

## الخطوة 3: كلاود فلير

1. Workers & Pages ← Create ← **Import a repository** ← `abdullah-travel` ← **Path: `whatsapp`**، الفرع `main`.
2. Settings ← Variables and Secrets، أضف (كلها Secret ما عدا رقم الهاتف):
   - `WA_TOKEN`، `WA_APP_SECRET`، `WA_PHONE_ID`
   - `WA_VERIFY_TOKEN`: أي كلمة تختارها (مثلاً `abdullah-2026`)
   - `ADMIN_TOKEN`: كلمة سر قوية لصفحة الإدارة
3. الرابط يصير مثل `https://abdullah-whatsapp.<اسمك>.workers.dev`.

إعدادات اختيارية: `DAILY_LIMIT` (250)، `SEND_HOURS` (`10-21`)، `MIN_DAYS` (3)، `HUMAN_HOURS` (12)، `STAFF_PHONE` (رقم المكتب).

## الخطوة 4: ربط ميتا بالبوت (Webhook)

بالتطبيق بميتا: WhatsApp ← **Configuration** ← Webhook ← Edit:

- **Callback URL:** `https://abdullah-whatsapp.<اسمك>.workers.dev/webhook`
- **Verify token:** نفس `WA_VERIFY_TOKEN`
- بعدها Manage ← فعّل: `messages`، `message_template_status_update`، `phone_number_quality_update`

جرّب: راسل رقم البوت «مرحبا» من موبايلك، لازم تطلعلك القائمة.

## الخطوة 5: الأرقام والحملة

1. **صدّر جهات الاتصال من الموبايل:**
   - أندرويد: تطبيق جهات الاتصال ← الإعدادات ← تصدير ← ملف `.vcf`.
   - آيفون: من <https://www.icloud.com/contacts> ← اختار الكل ← Export vCard.
   - Google Contacts: Export ← Google CSV.
2. افتح `https://abdullah-whatsapp.<اسمك>.workers.dev/admin`، ادخل بكلمة السر، وارفع الملف. الأرقام العراقية تتصلح وحدها والمكرر ينشال.
3. **حملة جديدة:** اسم القالب `travel_offers`، رابط الصورة، والمتغيرات.
4. اكتب رقمك ودوس **جرّب على رقمي**. إذا الرسالة زينة دوس **شغّل الإرسال**.
5. تابع من نفس الصفحة: كم انرسل، كم وصل، كم قرا، والمحادثات اللي تحتاج موظف.

## نصايح حتى ما تنزل جودة الرقم

- ميتا تشترط الشخص يكون موافق يستلم رسائل منك. ابدي بالزبائن اللي تعاملوا ويا المكتب، وخلي زر «إيقاف العروض» دايماً بالقالب.
- إذا الناس سوّت Block أو Report كثير، ميتا تنزّل الجودة. البوت يوكّف وحده، بس الأحسن تقلل الإرسال وتحسّن العرض.
- عرض واحد قوي أحسن من رسائل كثيرة. لا ترسل أكثر من مرة كل أسبوع.
- ميتا ممكن ما توصل الإعلان لشخص وصلته إعلانات كثيرة من شركات ثانية (يطلع «ميتا أجّلت»). هذا طبيعي وما تنحسب كلفته.

## للمطوّر

- `worker.js`: الروابط، والـDurable Object `Hub` (قاعدة SQLite: الأرقام، الحملات، الإرسال، المحادثات)، والإرسال على دفعات بالـalarm.
- `bot.js`: الردود (بلا إنترنت). الفحص: `node whatsapp/test.mjs`.
- `meta.js`: الاتصال بـGraph API والتحقق من توقيع الويب هوك.
- `admin.html`: صفحة الإدارة.
- `../src/bot.py`: يبني `bot.json` ويا الموقع.
- تجربة محلية: `npx wrangler dev` ويا ملف `.dev.vars` بنفس المتغيرات (و`GRAPH_URL` لسيرفر وهمي إذا ما تريد ترسل فعلاً).
